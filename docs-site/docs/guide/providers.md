# AI 供应商与模型

Aharou 自己不提供模型，你需要接入至少一个模型服务才能开始对话。这一页讲怎么配好它。

入口在「设置 → AI 配置 → AI 供应商」。

## 添加一个供应商

点右上角 +，会从底部弹出添加面板。列表第一项是**自定义供应商**（从空白手动配置），下面是内置的官方供应商（OpenAI、Anthropic、DeepSeek、智谱、通义等），两者样式一致。选内置供应商后自动填入名称、上游格式与 Base URL，进编辑页补上 API Key 就能用，也可以手动修改各项配置。

自定义配置时，填三样东西就能用：**上游格式**、**API Key**、**Base URL**。

- **上游格式**：`OpenAI` / `Anthropic` / `Gemini` 三选一，决定用哪种协议发请求。用第三方中转站的话，基本都选 `OpenAI`。
- **API Key**：你的密钥，形如 `sk-xxx`。粘贴时不用担心多带了空格或换行，保存时会自动清理。
- **Base URL**：只填 API 根地址，**不要带 `/v1` 或后面的具体路径**。留空会按上游格式自动填官方地址。
- **请求路径**：不用手动填，由**上游格式**自动推导——`OpenAI` 走 `v1/chat/completions`、`Anthropic` 走 `v1/messages`、`Gemini` 走 `v1beta`。若你的 Base URL 本身就是完整请求地址、不想再自动拼接，可在编辑页「选项」里打开**完整 URL** 开关。
- **名称**：给这个配置起个好认的名字，比如"我的中转"。列表里会按名字自动匹配品牌图标（填 DeepSeek 就显示 DeepSeek 的图标）。想用自己的图标，去「选项」里点「供应商图标」，可以从相册选一张图，也可以直接填图片链接；清空就恢复成按名字自动匹配的内置图标。自定义图标是本地文件，不包含在备份里：恢复备份后如果那张图不在本机了，会自动回落成按名字匹配的内置图标。

配完切到「模型」标签页拉取模型，就可以回主页开始对话了。

## 管理供应商列表

列表里每行显示名称、上游格式、模型数量和启用状态。

- 点一行进入编辑页。
- **左滑一行**露出红色删除按钮。
- **长按名称或上游格式信息区域上下拖动**可以调整顺序，重启后顺序保持。

## 多 Key 模式

::: tip 版本说明
多 Key 模式从 v1.11.0-dev 起提供。
:::

如果你手上有同一个服务的多个密钥，可以在编辑页的「选项」里打开**多 Key 模式**，密钥不可用时会自动切到下一个并**自动重发本次请求**，不需要手动重试。打开后原来的单 Key 输入框会隐藏，密钥统一在「多 Key 管理」页里维护（原本填的那个会自动成为列表第一项，不会丢）。

管理页里有三部分：

**Key 列表**：逐行增删，顺序就是优先级。展开某条 Key 后，其右侧的眼睛图标可以切换该条的明文/掩码显示。

**取用策略**：

- `顺序`：始终用靠前的 Key，不可用时才换下一个。
- `轮询`：新会话轮流从不同的 Key 起步，用来摊平多个 Key 的额度消耗。

为保护服务端 Prompt 缓存并维持会话连贯性，**单会话内默认保持同一个 Key**，只在当前 Key 被判定不可用时才换。

**失败切换**：

- `自动切换状态码`：命中这些 HTTP 状态码时立即切换并重发，默认 `401,402,403,429`；留空用默认值，也可以按需增删（逗号分隔）。
- `冷却时长`：被切走的 Key 隔多久重新参与候选，默认 5 分钟，也可以设成不冷却。

一次请求会依次尝试列表里的 Key，全部失败才报错（提示「N 个 Key 均失败」）。流式回复若已经开始输出内容，则不再重发（避免重复输出），只切换后续请求要用的 Key。触发切换时聊天区会出现「已切换到第 N/M 个 Key」提示。

鉴权失败、权限不足、触发限流、余额或额度用尽这些属于「密钥不可用」，会触发切换；服务器 5xx、请求超时、连不上网这些换 Key 也没用，仍走原有的网络重试。若所有 Key 都在冷却中，会直接报错让你稍后重试，不会拿已知不可用的 Key 硬打。

开启「自动重试增强」后，错误命中停止关键字时，同一供应商的请求会立即停止，也不会切换 Key 重发。未命中停止关键字时仍按上述规则切换；供应商单独配置的回退机制仍独立生效。

App 重启后会回到第一个 Key，冷却记录清空。

## 新版协议端点

编辑页的「选项」中支持切换到供应商的新版协议：
- **上游格式为 OpenAI 时**：可选开启「Response API (新版)」；
- **上游格式为 Gemini 时**：可选开启「Interactions API (新版)」。

默认保持关闭即可。请在确认所接入的官方直连或中转服务支持对应新协议时按需开启。

需要让 AI 检查已配置模型时，可以直接说「测试这个供应商的某个模型」。AI 使用内置测试动作发送极短请求，可能产生少量费用；不会修改配置，也不需要读取或回显密钥。测试结果只代表这次请求，不保证后续长对话、工具调用或所有模型能力都可用。

## 其它选项

::: v-pre
- **自定义请求头**：给这个供应商的所有请求追加自定义 Header，完全覆盖同名默认头（比如填 `User-Agent` 就替换掉默认 UA）。值里可以写 <code v-pre>{{SESSION_ID}}</code>（当前会话 id）和 <code v-pre>{{API_KEY}}</code>（本次实际取用的 Key）占位符，发送前自动替换。少数中转网关会校验特定 Header，需要时才填。
- **自定义面板脚本**：让供应商在输入框上方显示一个余额或用量卡片。脚本放在 `~/.aharou/scripts/` 下，支持 Python、Bash、Node，配好后可以在编辑页点「运行测试」看输出。脚本路径本身也可以通过**配置通道**读写（`providers.<id>.panel_script`），所以「换个面板脚本」可以让 AI 直接代改。卡片里的链接按钮（如「管理控制台」）点开后在**内置浏览器**里打开并自动弹出浏览器面板；写脚本时链接要指向人看的网页，不要填 API 地址。
- **脚本参数**：给面板脚本额外注入环境变量 `AICODE_KEY_<KEY>`。参数值里可以写 <code v-pre>{{PROVIDER_API_KEY}}</code>（当前 Key）、<code v-pre>{{BASE_URL}}</code>、<code v-pre>{{MODEL}}</code> 等占位符，运行脚本前自动替换。
- **回退供应商**：选一个备用供应商，当本供应商因为额度耗尽、鉴权失效或限流而失败时，自动切到备用供应商把本轮请求重发一次，不用你手动换。备用供应商也可以单独指定用哪个模型；留空就用它自己的当前模型。切换只在「这一轮还没吐任何内容」时发生，不会把半截回复拼到另一个模型上。它也能通过**配置通道**读写（`providers.<id>.fallback_provider_id`、`providers.<id>.fallback_model`）。
- **请求中间件**：用一段 JSON 给这个供应商改请求，目前支持两项：把某个模型名映射成真实模型（`modelMap`，界面上仍显示原名）、统一追加一段系统提示（`systemPrompt`，可用 `systemPromptTargets` 限定只对某些供应商类型/模型生效）。配置通道字段 `providers.<id>.request_middleware`。注意：参数覆盖（改 temperature 等）目前还没接入请求体，写了也不会生效。
:::

## 模型管理

切到编辑页的「模型」标签页。

**拉取模型**：点「拉取模型」向服务端同步可用列表，结果按品牌分组、可搜索。每个模型旁边有能力标签：`Image` 支持图片、`Tools` 支持工具调用、`↑` 后面是上下文长度、`↓` 后面是最大输出。拉取弹窗右上角提供「全部添加」按钮，点击并确认后可一键将拉取到的所有新模型批量加入当前供应商。

拉取成功后会自动对齐本地列表：远端已不存在的模型会直接从列表移除（拉取失败或返回空列表时不动本地列表）。如果你手动添加的模型恰好不在远端返回结果里，也会一并被移除，需要时重新添加即可；不想这样可以在[偏好设置](/guide/general)里关掉「拉取模型后自动移除无效模型」。

**批量操作与多选**：模型列表右上角提供「多选」按钮，点击即可进入批量选择模式：
- **全选 / 取消全选**：一键勾选所有模型或清空选择。
- **测试**：对选中的所有模型依次发起连通性测试。成功需要 HTTP 和对应协议的业务响应都有效，网关返回 HTML、业务错误或畸形数据不会显示连接正常；达到输出上限而没有正文等合法协议响应仍可通过。
- **批量删除**：二次确认后批量删除选中的模型。
- 点左上角返回箭头或按返回键即可退出多选模式。

**手动添加**：中转站的模型名有时拉不全，可以点 + 手动输入模型名添加。编辑弹窗里还能自定义这个模型的：

- **显示名**：给这个模型起个别名，列表里就显示这个名字（留空则显示原始模型名）。调用的还是原来那个模型，只是看着好认。
- **模型图标**：可以给它单独配一张图（从相册选，或填图片链接），不设置就按模型名自动匹配内置品牌图标。图标是本地文件，不包含在备份里。
- **上下文窗口**：影响什么时候触发上下文自动压缩。
- **输出窗口**：单次回复的最大长度。
- **价格**：输入 / 输出 / 缓存读取 / 缓存写入四档，单位是美元每百万 token，用于费用统计。
- **能力开关**：图片输入、图片输出、工具调用、推理能力。

窗口值需填写有效的正整数，也可留空使用自动识别值；填写 0、负数、小数或超出范围的整数时会显示提示，且无法保存。编辑已有模型时，只改价格不会改变原有的总上下文、输入和输出窗口。
你填的值优先级最高；没填的会回退到自动识别的结果，自定义设置始终对应当前供应商下的原模型名。自动识别优先匹配完整名称，再尝试忽略大小写；仍未找到时尝试去掉 `-thinking`、`-preview`、`-high` 这类常见后缀，并尝试去掉供应商品牌前缀。上述尝试均失败后，才去掉最后一个 `-` 及其后面的部分匹配一次，不会反复截短名称。

**思考强度**：点击输入栏模型按钮，在模型列表中点击具体模型的「思考」标签设置档位。始终列出全部七档——`不思考` / `默认` / `低` / `中` / `高` / `极高` / `最高`：

- `不思考`：尝试使用当前规则的关闭参数；未生成明确关闭参数时会提示，不能把隐藏思考过程当成关闭推理。
- `默认`：推理配置不主动指定强度或预算，由服务商按默认处理；固定自定义请求仍可能指定这些参数。
- 其余档位通过模型推理配置生成参数。等级型协议中，「极高」发送 `xhigh`，「最高」发送 `max`，不会自动降成 `high`；预算型协议仍使用各档 Token 预算。服务商不支持某个等级时可能拒绝请求，可手动配置映射或改选档位。

之所以不按模型自动筛选：模型支持哪些档位是服务商声明的，实际经常报不全（例如只报 `low` / `high` / `max`），筛完就选不到「中」这类中间档了。选择会按模型记住，下次新会话用这个模型时自动沿用；没调过的模型则以「默认」起步（新会话不再默认发 `medium`）。AI 正在运行时，当前模型的档位暂时不可修改，其他模型的默认档位仍可设置。

## 服务档位

在模型行的「思考」弹层中，OpenAI 类型模型可切换到「服务档位」页签，选择跟随上游、标准、Fast 或 Ultrafast。选择按供应商和模型分别保存，与思考强度独立；当前模型正在运行时暂时不可改。

跟随上游不主动发送服务档位参数，标准发送 `default`，加速档位发送 `fast` 或 `ultrafast`。是否支持、速度和费用由所用渠道决定，不能保证所有 OpenAI 兼容服务都接受；不支持时可改回跟随上游。模型测试与实际调用都读取该模型的选择，固定自定义请求 JSON 仍最后覆盖。标题、压缩等后台任务的思考强度选择保持原有语义。

## 推理配置

完整地址使用所选供应商协议下可识别的端点时，聊天、模型测试和参数预览会按该端点一致选择请求格式，例如 OpenAI 的 Chat Completions／Responses、Gemini 的 generateContent／Interactions；其他自定义路径继续按协议开关处理。

模型编辑弹窗中点「推理配置」，或在聊天模型的思考档位弹层中点「配置推理参数」，可设置该供应商下这个模型的参数映射。同名模型在不同供应商下分别保存。

- **参数表达方式**：自动识别、OpenAI 强度、Anthropic 预算／自适应、Gemini 预算／等级、兼容渠道的思考开关、自定义 JSON。自动识别兼容模型名大小写、厂商前缀及版本分隔符，区分 Claude 的预算／自适应代际、Gemini 2.5 预算与 Gemini 3/4 等级；厂商专属字段只按已知的真实域名识别，不因网址路径含厂商名而启用。手动设置适用于中转站或特殊模型。
- **兼容渠道识别**：DeepSeek 官方 V4/Flash 的 Chat 请求会同时发送思考开关与所选等级，Responses 使用对应的推理对象。DashScope 的已知 QwQ／thinking-only 模型不会自动发送关闭开关；此时会提示未生成关闭参数。未知网关仍使用通用规则，手动配置可覆盖识别结果。
- **逐档设置**：参数值、思考 Token 预算和 JSON 对象。留空继承，字段旁可单独重置；「恢复自动配置」清除整份手动覆盖。预算只用于支持预算的表达方式。
- **默认与关闭**：「默认」仅供预览，不配置映射；「不思考」可配置参数值或 JSON，但不设置预算。七档始终可见，不因模型元数据缺失而隐藏。Claude 的思考能力按具体家族和版本区分：Mythos Preview、Fable/Mythos 5/5.1、Opus 5.5 与 Sonnet 5.5 不自动发送完全关闭参数，而是保留提示。Sonnet 5.5 的工具间思考不等于完全关闭，不能用它冒充「不思考」。
- **预览**：展示将发送的推理字段和固定请求覆盖来源，敏感值以遮罩显示。切换预览档位不改变聊天选择；保存只改变参数映射，不另存一份默认档位。

截至 2026-11-09，模型名里的厂商前缀、点号版本、Bedrock 的区域前缀与 Vertex 的日期后缀只用于识别，不改写实际发送的模型名。日期快照不当作小版本；「默认」只表示本应用不指定强度，部分新模型在服务端仍默认开启思考。

生成顺序为：基础请求 → 当前档位的推理参数及逐档 JSON → 固定自定义请求。固定请求仍按模型高于供应商、供应商高于全局合并。例如选择「高」，而模型固定请求指定 low，预览会显示 low 并标明模型覆盖；切换档位不会自动修改固定请求 JSON。

协议不兼容、预算超出声明范围、互斥字段或无法明确关闭时，预览会提示。Gemini 原生协议目前声明的等级为 minimal/low/medium/high；选择 xhigh/max 时会提示风险，但仍原样发送，不替用户降档。自动生成的 Anthropic 预算最低为 1024，并为正文预留输出空间；固定 JSON 仍原样覆盖，需自行修正不合法的组合。预览不保证服务端支持这些参数，保存后的模型「测试」会使用模型默认档位和推理配置发送真实请求，可能产生推理费用。

配置及其审计值加密保存在本机，不包含在应用备份中，换机需重设；删除模型／供应商会清除对应配置，编辑模型名称时会保留当前配置。已有会话档位与模型默认档位不重置。标题、压缩等后台调用继续使用自身默认强度，不自动继承聊天高档位。

## 自定义请求

「偏好设置 → 网络 → 自定义请求」设置全局请求头和请求体；供应商编辑页的「选项」以及模型编辑弹窗可分别设置供应商级、模型级覆盖。三层优先级为模型高于供应商、供应商高于全局。原有的供应商自定义请求头仍然有效。

请求头和请求体分别填写 JSON 对象。请求头的值须为字符串；请求体对象中的字段值可以是对象、数组、字符串、数字、布尔值或 `null`。对象会递归合并，数组和其他值会整体覆盖，`thinking`、`reasoning` 与 `thinkingConfig` 也整体覆盖。请按供应商支持的协议填写；若参数不受支持，测试或对话会返回服务端错误。配置加密保存在本机，不包含在应用备份中，换机后需要重新设置。

模型列表拉取使用全局和供应商请求头；模型测试与聊天请求使用三层配置。自定义请求体会影响实际发送的参数，可能覆盖默认值与推理配置；可在「推理配置」中查看覆盖来源。

删除模型会同时清除其请求覆盖；重命名模型会把当前覆盖保存到新名称，旧名称重新添加后不会恢复旧覆盖。通过配置通道修改时，审计记录中的请求值也会加密保存，删除模型或供应商后仍保持遮罩显示。

**测试**：每个模型行都有「测试」按钮，发一次真实请求验证连通性，结果显示在行下方。

**排序**：长按模型名称区域上下拖动，可以调整模型顺序，保存后立即生效（模型选择弹窗与默认模型列表都按这个顺序展示），重启后顺序保持。

**删除**：模型行左滑删除。如果删掉的模型正在被使用（当前供应商的选中模型、新会话默认模型、识图 / 生图 / 压缩 / 标题模型，或者某个历史会话绑定的模型），相关选择会自动回退到默认模型，不会再拿已删除的模型发请求。
